# Clear Up · كلير أب

**شركة تطوير أعمال وتسويق ابتكاري من غزة.**

هذا المستودع هو الموقع الرسمي لـ Clear Up، ومعه لوحة التحكم التي يدير منها الفريق كل محتوى الموقع بنفسه، بدون مبرمج.

---

## عن الشركة

تبني Clear Up للمؤسسات أنظمة ابتكار وذكاء اصطناعي تصنع نمواً مستداماً. تعمل مع قادة الشركات الصغيرة والمتوسطة ومدراء المؤسسات التنموية على تحويل الأفكار والتمويل إلى نمو حقيقي يمكن قياسه:

- تختبر الطلب في السوق قبل البناء.
- تطلق المنتجات والخدمات وتطوّرها.
- تبني داخل فرق العملاء القدرة على الابتكار، حتى يستمر النمو بعد انتهاء عملها.

القاعدة التي تعمل بها الشركة، كما يقولها مؤسسها عبد المنعم: **«راهن كبيراً، واختبر صغيراً».**

## الموقع

موقع بلغتين (العربية والإنجليزية)، مصمم للجوال أولاً، وصفحاته:

- **الرئيسية:** العرض الأساسي، فيديو تعريفي، شريط العملاء، الخدمات الخمس، النتائج، آراء العملاء، الأسئلة الشائعة، وحجز مكالمة.
- **الخدمات والنظام:** كل خدمة بالتفصيل (التحدي، ماذا نفعل، كيف نعمل، ماذا تحصل عليه) مع فيديو، في عرض تفاعلي يتبع التمرير.
- **أعمالنا:** قصص العملاء، ولكل قصة صفحة خاصة.
- **من نحن** و**تواصل**.

وفيه أيضاً مساعد محادثة يجيب الزوار من محتوى الموقع نفسه، ويحوّلهم إلى واتساب عند الحاجة.

---

## لوحة التحكم

لوحة عربية على الرابط `/admin`، مبنية داخل الموقع نفسه:

- **محرر مرئي:** الموقع الحقيقي على جهة والتعديل على الجهة الأخرى، وكل تغيير يظهر فوراً كمسودة قبل النشر.
- **الأقسام:** ترتيب بالسحب، إظهار وإخفاء، نسخ، حذف، وإضافة أقسام جديدة. لكل نص خانة عربي وخانة إنجليزي.
- **الإعدادات:** الشعار، الألوان، الخط، واتساب، السوشال، القائمة، الفوتر، وبيانات محركات البحث.
- **النشر:** المسودة تُحفظ تلقائياً، وزر «نشر» واحد يحدّث الموقع خلال ثوانٍ.
- **السجل والنسخ الاحتياطي:** كل نشر محفوظ مع رجوع بضغطة، وتنزيل نسخة كاملة من المحتوى واستعادتها.

دليل اللوحة بالعربي: [`docs/ClearUp_admin_guide_ar.pdf`](docs/ClearUp_admin_guide_ar.pdf)

## كيف تم تطوير المنصة

### البداية

بدأ المشروع كنموذج تصميم حي مبني على دراسة لمواقع المنافسين ([`docs/ClearUp_Competitor_Review.pdf`](docs/ClearUp_Competitor_Review.pdf)) وملاحظة تصميم ([`docs/ClearUp_Design_Note_AR.pdf`](docs/ClearUp_Design_Note_AR.pdf)). الفكرة البصرية: **من الفوضى إلى الوضوح**، وهي ترجمة لاسم Clear Up نفسه.

### إدارة المحتوى

استُخدم في البداية نظام إدارة محتوى خارجي، ثم استُبدل بلوحة تحكم عربية مبنية داخل الموقع، أسهل على الفريق ولا تعتمد على أي خدمة خارجية. نُقل المحتوى كاملاً إليها، ثم تحوّل الموقع من صفحة واحدة إلى عدة صفحات.

### التطوير المستمر

تطوّر الموقع على جولات قصيرة من ملاحظات الفريق: كل جولة تُجرَّب على الجوال والكمبيوتر، وتُثبَّت باختبارات آلية قبل النشر. من أبرز ما أُضيف:

- عرض الخدمات التفاعلي، بحيث يظهر كامل نص كل خدمة على أي شاشة.
- مشغّل فيديو واحد للموقع كله: يفتح على الكمبيوتر كنافذة بشكل الريل، وعلى الجوال بكامل الشاشة كالستوري.
- شعارات العملاء، وآراؤهم بالفيديو، وصفحة لكل قصة عميل.
- تحسين السرعة على الجوال.

### التقنيات

| الجزء | التقنية |
|---|---|
| الموقع | Next.js 16 و React 19 و TypeScript |
| قاعدة البيانات | PostgreSQL على Neon، عبر Drizzle ORM |
| الصور والفيديو | Cloudinary |
| رسائل نموذج التواصل | Resend |
| مساعد المحادثة | Gemini أو Groq (اختياري) |
| الخط | ثمانية (Thmanyah Sans) |
| الاستضافة | Netlify |

### كيف يعمل

- **الزائر لا يلمس قاعدة البيانات:** الصفحات تُجهَّز مسبقاً وتتحدث عند كل نشر من اللوحة، فيبقى الموقع سريعاً.
- **لا يتعطل الموقع:** إذا لم تكن قاعدة البيانات متاحة وقت البناء، يُبنى من نسخة محفوظة من المحتوى (`seed/content.json`).
- **الأمان:** كلمات المرور مشفّرة، والدخول يُقفل مؤقتاً بعد محاولات خاطئة متكررة، وكل حفظ يُفحص على السيرفر قبل قبوله، ولا يصل أي مفتاح سري إلى المتصفح.

## للمطورين

<div dir="ltr">

```bash
npm install
cp .env.example .env.local        # DATABASE_URL, ADMIN_SESSION_SECRET, CLOUDINARY_URL …
npm run db:migrate                # create the tables (safe to re-run)
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='a-long-password' npm run db:seed
npm run dev                       # http://localhost:3000/ar/  and  /admin

npm run typecheck && npm run lint && npm test && npm run build
```

</div>

- المتغيرات كلها موصوفة في [`.env.example`](.env.example).
- لإضافة نوع قسم جديد: عرّف حقوله في `src/admin/schema.json`، واكتب شكله في `src/components/`، وأضفه في `src/components/Sections.tsx`.
- ملفات خط ثمانية في `public/fonts/thmanyah/` تخضع لترخيص ثمانية: مجانية للاستخدام لكن لا يجوز إعادة توزيعها.
